# Processes

A process document describes a repeatable operational procedure, such as a monthly certificate expiry check or a post-deployment binding check.

## Adding a process

1. Copy [_template.md](_template.md) to `short_description.md` in this folder and fill it in.
2. Add a row to [index.md](index.md).

## Kit files and organisation files

This README and `_template.md` are kit files, replaced when the kit is upgraded. Your process documents and [index.md](index.md) are organisation files, which the kit never overwrites (see `README.md` at the repository root).
