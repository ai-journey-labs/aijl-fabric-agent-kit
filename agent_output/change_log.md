# Change log

Every change to the organisation's Fabric environment, or to this agent, has one row here. IDs are `CHG-###`, sequential and never reused, including for changes that are superseded or abandoned. With several operators, pull `main` before allocating an ID and push the allocation before starting work.

Status values: Review / Planned / Awaiting approval / Approved / Implementing / Implemented / Closed / Superseded
